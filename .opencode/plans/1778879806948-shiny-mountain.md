### Task 3: Migrate cmd/go-aws-sso/main.go

**Imports:** Replace `cli/v2` + `cli/v2/altsrc` with `cli/v3`. Remove altsrc imports. Add `"context"`.

**Flags:** Remove all `altsrc.NewStringFlag()`/`altsrc.NewBoolFlag()` wrappers, use plain `&cli.StringFlag{}`/`&cli.BoolFlag{}`.

**VersionPrinter:** Change `func(c *cli.Context)` → `func(cmd *cli.Command)`.

**readConfigFile:** Rewrite from altsrc-based to manual YAML read + `cmd.Set()` approach:
```go
func readConfigFile(cmd *cli.Command) error {
    configPath := ConfigFilePath()
    if _, err := os.ReadFile(configPath); err != nil {
        return nil // config file is optional
    }
    config := ReadConfig(configPath)
    if config.StartUrl != "" && !cmd.IsSet("start-url") {
        if err := cmd.Set("start-url", config.StartUrl); err != nil {
            return err
        }
    }
    if config.Region != "" && !cmd.IsSet("region") {
        if err := cmd.Set("region", config.Region); err != nil {
            return err
        }
    }
    return nil
}
```

**CLI Definition:**
- `cli.App{...}` → `cli.Command{...}`
- `EnableBashCompletion` → `EnableShellCompletion`
- `Subcommands` → `Commands`
- All Action funcs: `func(context *cli.Context) error` → `func(ctx context.Context, cmd *cli.Command) error`
- All Before funcs: `readConfigFile(initialFlags)` → `func(ctx context.Context, cmd *cli.Command) (context.Context, error) { return ctx, readConfigFile(cmd) }`
- `app.Run(os.Args)` → `cmd.Run(context.Background(), os.Args)`
- Replace all `context.String/Bool/Args/Set` → `cmd.String/Bool/Args/Set` in inline handlers

**Helper functions** (`start`, `checkMandatoryFlags`, `applyForceFlag`, `initializeLogger`):
- Change `context *cli.Context` → `cmd *cli.Command`
- Replace all `context.` → `cmd.`
- In `checkMandatoryFlags`: `GenerateConfigAction(context)` → `GenerateConfigAction(context.Background(), cmd)`
