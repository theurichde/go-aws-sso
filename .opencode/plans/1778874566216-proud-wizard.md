# Fix 2 Remaining Critical Issues

## Issue 3: Headless mode detection is broken

### Problem
`pkg/sso/aws.go:175` uses `strings.Contains(strings.Join(os.Args, ","), "--headless")` which is:
- A fragile substring match on raw args (false positives/negatives)
- Unaware of the YAML config source (`altsrc`) — `--headless` set in config file is invisible
- The parsed `context.Bool("headless")` is available in every caller but never passed down

### Fix: Thread `headless bool` through 4 functions + 5+ call sites

**Functions to add `headless bool` parameter to** (all in `pkg/sso/aws.go`):

| Function | Line | New signature |
|---|---|---|
| `startDeviceAuthorization` | 169 | `func startDeviceAuthorization(oidc ..., rco ..., startUrl string, headless bool) ...` |
| `registerClient` | 152 | `func registerClient(oidc ..., startUrl string, headless bool) *ClientInformation` |
| `ProcessClientInformation` | 106 | `func ProcessClientInformation(oidcClient ..., startUrl string, headless bool) ClientInformation` |
| `handleOutdatedAccessToken` | 134 | `func handleOutdatedAccessToken(clientInformation ..., oidcClient ..., startUrl string, headless bool) ClientInformation` |

**In `startDeviceAuthorization` (line 175):**
- Replace: `if !strings.Contains(strings.Join(os.Args, ","), "--headless") {`
- With: `if !headless {`
- Ensure `"os"` import is NOT removed in case it's used elsewhere in the file

**Call sites that need changes:**

| File | Line | Current call | Change |
|---|---|---|---|
| `cmd/go-aws-sso/main.go` | 170 | `start(oidcApi, ssoApi, context, Prompter{})` | Extract `headless := context.Bool("headless")` inside `start()` |
| `cmd/go-aws-sso/main.go` | 201-204 | `ProcessClientInformation(oidcClient, startUrl)` in `start()` | `ProcessClientInformation(oidcClient, startUrl, headless)` |
| `cmd/go-aws-sso/main.go` | 229-232 | `ProcessClientInformation(oidcClient, startUrl)` in `retryWithNewClientCreds` | Add `headless bool` param to `retryWithNewClientCreds`, pass to call |
| `internal/refresh.go` | 23-28 | `ProcessClientInformation(oidcClient, startUrl)` in `RefreshCredentials` | Extract `headless := context.Bool("headless")`, pass to call |
| `internal/refresh.go` | 42 | `retryWithNewClientCreds(oidcClient, ssoClient, startUrl)` | Pass `headless` |
| `internal/refresh.go` | 67-70 | `retryWithNewClientCreds` signature + `ProcessClientInformation` call | Add `headless bool` param |
| `internal/assume.go` | 18-22 | `ProcessClientInformation(oidcClient, startUrl)` in `AssumeDirectly` | Extract `headless := context.Bool("headless")`, pass to call |

## Issue 4: `applyForceFlag` unconditionally logs success

### Problem
`cmd/go-aws-sso/main.go:258-271` — The success log messages on lines 264 and 269 execute unconditionally, even when `os.Remove` failed and nothing was actually removed.

### Fix: Move success logs into `else` blocks

**File:** `cmd/go-aws-sso/main.go`, function `applyForceFlag`

Change from:
```go
err := os.Remove(ClientInfoFileDestination())
if err != nil {
    zap.S().Infof("Nothing to do, no temporary access token found")
}
zap.S().Infof("Removed temporary access token")        // always prints
err = os.Remove(os.TempDir() + "/go-aws-sso.lock")
if err != nil {
    zap.S().Debugf("Nothing to do, no temporary lock file found")
}
zap.S().Infof("Removed temporary lock file")            // always prints
```

To:
```go
err := os.Remove(ClientInfoFileDestination())
if err != nil {
    zap.S().Infof("Nothing to do, no temporary access token found")
} else {
    zap.S().Infof("Removed temporary access token")
}
err = os.Remove(os.TempDir() + "/go-aws-sso.lock")
if err != nil {
    zap.S().Debugf("Nothing to do, no temporary lock file found")
} else {
    zap.S().Infof("Removed temporary lock file")
}
```
